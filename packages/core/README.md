# @devvy-ui/core

Framework-independent, DOM-free utilities. `getNavigationIndex` implements enabled-item
navigation with Home, End, wrapping, vertical orientation and RTL. Adapters own rendering,
focus and state. `cx` joins optional class names. No global events or browser globals.

Part of the fixed DEVVY UI stable release group. React-local hooks and DOM effects belong to the React
adapter, not this package. See repository docs/compatibility.md for tested targets.
