# @devvy-ui/tokens

Plain CSS variables for Devvy UI. Import `@devvy-ui/tokens/theme.css`.

Set `data-devvy-theme="light"` or `data-devvy-theme="dark"` on `<html>` to override automatic color-scheme detection. Without an explicit theme, the OS preference is respected.

Part of the fixed DEVVY UI stable release group. Tokens remain framework-independent and support scoped
light/dark/system modes. See repository docs/customization.md before changing contrast,
density, typography or motion. Glass material variables remain an optional enhancement.
