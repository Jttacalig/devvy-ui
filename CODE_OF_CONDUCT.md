# Code of Conduct

We want Devvy UI to be a welcoming, technically rigorous place to collaborate.

Be respectful and constructive. Critique ideas and code rather than people. Harassment, discrimination, threats, and publication of private information are not tolerated.

Maintainers may edit or remove harmful content, restrict participation, or ban accounts that repeatedly violate these expectations. Report conduct concerns to repository maintainers privately through their GitHub profiles or a private contact channel listed once the project is published. Do not post sensitive personal details in public issues.
