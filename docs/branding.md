# DEVVY UI logo

The project uses the transparent logo supplied by the owner on 21 October 2026.
The original PNG is preserved in apps/docs/public/devvy-logo.png and copied unchanged
to examples/vite-react/public/devvy-logo.png. These files contain the same bytes.

The docs header, preview workspace, Vite header and favicons use this asset. A dark
backplate keeps the silver logo legible in both light and dark themes. Redundant logo
images have empty alt text beside the visible product name. The standalone Vite header
uses a DEVVY UI alt name.

to imply endorsement. Confirm brand-asset rights before public redistribution.
