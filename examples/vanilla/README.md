# Vanilla CSS example

Open index.html locally. It imports only the shared tokens and styles and uses native
HTML controls. No JavaScript, framework adapter, tabs or overlays are implied.
The form submits a local GET query; it has no backend. In a deployed site serve the CSS
as static assets at paths appropriate to your application.

The shared 0.2.0 stylesheet includes React component classes too; loading CSS does not
provide their React behavior to vanilla HTML. Use the native controls shown here.
