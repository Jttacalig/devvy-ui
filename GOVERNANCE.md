# Project governance

Devvy UI is an open-source project by Dev Station, maintained initially by its repository owners.

- Contributions are welcome by pull request under the MIT license.
- Maintainers have final responsibility for package publication, release quality, security and project direction.
- Public roadmap discussion is encouraged; implementation proposals should identify accessibility and compatibility trade-offs.
- This governance model may evolve as regular maintainers join.
